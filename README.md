# PosturePal
Collected real-time posture data using ESP32, IMU, and ultrasonic sensors. Processed and analyzed sensor data to detect incorrect posture patterns. Visualized posture readings using an IoT dashboard. Generated alerts based on data conditions. Demonstrated strong data interpretation and system optimization skills.
In the Wifi Credintals (ssid part) insert the name of your Wifi Network and in the password section insert your Wifi password.
